For exp 7 and 8, color-app and spa-app (single page application)  
This is how you get boilerplate and then put the code inside App.js  
Currently directly full folder is given on repo but if you want to do manually then follow these steps and then just copy-paste code from App.js of repo into your App.js   
  
Location of App.js is as follow-  
  
  
color-app/spa-app  
  >src  
    >App.js  


now the code of boilerplate for "color-app"  
doing these step-by-step will automatically create a folder and required files inside it  
Highly recommended to do once at home  
Remember this is for WINDOWS ! steps for UBUNTU will be added soon !  
  
color-app steps-  
  
```npx create-react-app color-app          //create folder with required files  ```  
```cd color-app                            //go to directory of color-app  ```  
```npm start                               //start server/website  ```  

spa-app steps-

```npx create-react-app spa-app           //create folder with required files  ```  
```cd spa-app                             //go to directory of spa-app  ```  
```npm install react-router-dom           //install needed dom thing  ```  
```npm start                              //start server/website  ```  
  
after doing this the website won't show anything before you put main code inside "App.js"  
the website start on "available" localhost ports like 8000, 3000
